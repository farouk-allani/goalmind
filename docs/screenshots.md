## Dark Theme

GoalMind uses a dark theme optimized for:
- Stadium environments (low light)
- Battery saving (OLED screens)
- Modern aesthetics

## Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Background | #0a0a0a | Main background |
| Surface | #141414 | Card backgrounds |
| Primary | #10b981 | CTAs, highlights |
| Secondary | #6366f1 | Secondary actions |
| Accent | #f59e0b | Warnings, badges |
| Text | #f5f5f5 | Primary text |
| Text Muted | #a3a3a3 | Secondary text |
| Border | #262626 | Dividers |

## Typography

- **Headings:** Inter 800 (extrabold)
- **Body:** Inter 400 (regular)
- **Labels:** Inter 600 (semibold)
- **Monospace:** JetBrains Mono (addresses, code)

## Components

- **Button:** 4 variants (primary, secondary, outline, ghost)
- **Card:** 3 variants (default, elevated, outlined)
- **Badge:** 2 variants (filled, outline)
- **Progress Bar:** Configurable color and height
- **Stat:** Label + value + optional change
